# 07. Production Baseline

## Готовность системы

Система считается готовой если:

- Нет прямых записей в IO
- Все команды идут через COMMAND
- Safety имеет приоритет
- INPUT слой валидирует данные
- Scenario не читает STATE

## Ограничения

- Нельзя обходить pipeline
- Нельзя писать в чужие GVL
- Нельзя управлять IO из HMI

## Изменения

Любое изменение должно:

1. Сохранять pipeline
2. Не ломать safety
3. Не нарушать ownership

Система готова к эксплуатации
