# 05. HMI / Debug Dashboard

## Назначение

Read-only представление состояния системы.

## Отображает

- Safety mode
- Scenario
- Intent
- Confidence
- Worst zone
- Anomaly / Validation

## Принцип

```text
HMI НЕ управляет системой
```

## Explainability

- Почему выбран сценарий
- Почему заблокировано отопление
- Почему открыты замки

## Диагностика

Позволяет выявить:
- плохие датчики
- деградацию системы
- аварии
