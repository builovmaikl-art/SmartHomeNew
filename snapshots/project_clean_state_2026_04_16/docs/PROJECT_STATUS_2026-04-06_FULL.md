### 1. Legacy System
- PRG_System
- существующие FB
- работает как "источник истины"

### 2. CoreKernel (NEW)
- чистая логика
- без GVL зависимостей
- детерминированное поведение

### 3. Shadow Layer
- повторное вычисление логики
- не влияет на систему

### 4. Comparison Layer
- сравнение legacy vs shadow
- сигнал: `VO_Diff_Found`

### 5. Observer Layer
- подключение в runtime
- read-only
