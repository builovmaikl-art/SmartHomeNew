# IO Mapping Concept

## 📌 Суть

Логика не зависит от физического входа ПЛК.

## 🔧 Уровни

1. Logical (что это)
2. Mapping (куда подключено)
3. Physical IO (реальный вход)

## 🎯 Зачем

- гибкость
- ремонтопригодность
- масштабируемость

## 🧠 Пример

LeakSensor_Bathroom_1 → DI_14

При поломке:
→ DI_22 (через HMI)

Без изменения логики.
