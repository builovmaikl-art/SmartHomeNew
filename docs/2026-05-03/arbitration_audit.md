# Command Arbitration Audit (2026-05-03)

## Цель

Обеспечить детерминированное и безопасное формирование команд управления.

---

## Найденные проблемы

1. Множественные точки записи в GVL_COMMAND_SHADOW
2. Отсутствие строгой приоритизации источников
3. Возможны гонки (race conditions)
4. Неявное поведение при неизвестных режимах

---

## Исправления

### 1. Single Point Write

Введён локальный буфер L_*:

- Все вычисления выполняются в локальных переменных
- Финальная запись происходит ОДИН раз

### 2. Детерминированная модель

Pipeline:

1. PLC role validation
2. PLC inactive handling
3. Safety mode arbitration
4. Conflict resolution
5. Final write

### 3. Fail-safe

- Любой неизвестный режим → полный STOP

### 4. Приоритеты

| Приоритет | Источник        |
|----------|----------------|
| 1        | PLC conflict   |
| 2        | PLC inactive   |
| 3        | Safety mode    |
| 4        | Default        |

✔ Повышена безопасность системы
