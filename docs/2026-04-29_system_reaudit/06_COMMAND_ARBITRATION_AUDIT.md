## Key observations

### AUD-036 (Positive)

Use of:

GVL_COMMAND_SHADOW

Confirms architecture:

Intent → Arbitration → Shadow → Actuation

---

### AUD-037 (Positive)

Safety intents are correctly enforced:

- Fire alarm → stop boiler, open locks
- Gas → close valve + stop boiler
- Water → close valves

This is correct direction.

---

### AUD-038 (Critical)

No usage of:

GVL_POLICY

Meaning:

Policy decisions do NOT affect commands.

This breaks pipeline:

Policy → (missing) → Command

---

### AUD-039

No structured priority system:

Example:

User opens gate
Safety may require lock open

No explicit arbitration rule:

Safety > System > User

Currently order-dependent only.
