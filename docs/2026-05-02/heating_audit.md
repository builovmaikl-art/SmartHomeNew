# Heating Core Audit (2026-05-02)

## Найденные проблемы

1. Block Heating применялся только к зонам и коллекторам
2. Котёл, DHW и backup насос могли оставаться активными
3. Нарушение safety-инварианта (block ≠ полный стоп)

## Исправления

1. Расширен FB_Heating_Override_Layer
   - теперь управляет ВСЕМИ выходами

2. Обновлён FB_Heating_Orchestration
   - передаёт полный набор outputs в override

## Результат

✔ Block Heating теперь глобальный
✔ Нет частичного останова
✔ Нет риска перегрева при блокировке

## Вывод

Критический дефект управления устранён.
