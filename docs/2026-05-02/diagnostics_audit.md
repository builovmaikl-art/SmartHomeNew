# Diagnostics Audit (2026-05-02)

## Найденные проблемы

1. Нет привязки ко времени (зависимость от scan time)
2. Нет decay модели
3. Ошибки не нормализованы
4. Нет состояний системы (OK/DEGRADED/CRITICAL)

## Исправления

1. Введён delta-time (нормализация по времени)
2. Добавлена decay модель (health зависит от времени)
3. Усилено влияние ошибок
4. Добавлены состояния системы

## Добавлено: state thresholds

- Heating: OK >0.7, DEGRADED >0.3, CRITICAL <=0.3
- Safety: OK >0.8, DEGRADED >0.4, CRITICAL <=0.4
- IO: OK >0.7, DEGRADED >0.3, CRITICAL <=0.3

✔ Diagnostics стал time-based

✔ Поведение предсказуемое
